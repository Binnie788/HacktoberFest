## 📸 The Problem & The Solution

Most mobile camera applications function purely as passive optical collectors: they record whatever is pointed in front of the lens. Critical compositional factors — such as the Rule of Thirds, horizon leveling, subject lead room, lighting balance, and camera perspective — are left entirely to trial and error.

**Lumina Camera** elevates the mobile viewfinder into an active, intelligent creative director using a **Dual-Loop Architecture**:

1. **Fast Loop (~30 FPS, Zero-Latency On-Device):**
   - High-rate horizon tilt and pitch sensing with instant visual leveling feedback.
   - On-device subject tracking in a dedicated Web Worker without main thread jank.
   - Automatic Rule-of-Thirds power point snapping: overlay grid glows vibrant emerald when subject intersects the golden compositional coordinates.
   - Real-time Laplacian variance (sharpness/blur detection) and luminance analysis.
   - 500ms stability accumulator with tactile haptic confirmation.

2. **Slow Loop (2–3s, Asynchronous Gemma 4 Open-Weight AI):**
   - Photographic critique generated by Google DeepMind's open-weight **Gemma 4** (`gemma-4-26b-a4b-it` Mixture-of-Experts or `gemma-4-31b-it` dense).
   - Actionable, concise suggestions strictly enforced to **≤ 12 words** (e.g. *"Pan left slightly to align subject on vertical third line"*).
   - HUD movement guidance vectors, suggested zoom factor, exposure correction hints, and aesthetic composition score (0–100).
   - Dual-mode execution: cloud-hosted via Google AI Studio, or **100% air-gapped self-hosted** via Ollama / local runners.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- Python (3.11+)
- *For self-hosted mode:* [Ollama](https://ollama.com) installed locally

---

### Mode A: Hosted Mode (Google AI Studio)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/lumina-camera.git
   cd lumina-camera
   ```

2. **Configure the backend:**
   ```bash
   cd backend
   pip install -r requirements.txt
   cp .env.example .env
   ```
   Edit `.env` to supply your free Gemini API key:
   ```env
   LLM_PROVIDER=gemini
   GEMINI_API_KEY=AIzaSyYourGoogleAIStudioKeyHere
   GEMMA_MODEL_NAME=gemma-4-26b-a4b-it
   ```

3. **Verify model connectivity:**
   ```bash
   python test_gemma.py
   ```

4. **Start the backend:**
   ```bash
   python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```

5. **Start the web client:**
   ```bash
   cd ../web
   npm install
   npm run dev
   ```
   Open `http://localhost:5173`.

---

### Mode B: 100% Self-Hosted Mode (Air-Gapped Ollama)

Lumina Camera can run completely offline without sending any data to external cloud providers.

1. **Pull and start Gemma 4 in Ollama:**
   ```bash
   ollama run gemma4:26b
   # Or for lower VRAM hardware:
   # ollama run gemma4:e4b
   ```

2. **Configure backend `.env`:**
   ```env
   LLM_PROVIDER=ollama
   OLLAMA_BASE_URL=http://localhost:11434
   OLLAMA_MODEL=gemma4:26b
   ```

3. **Start backend and frontend:**
   ```bash
   # Backend
   python -m uvicorn app.main:app --port 8000
   # Frontend
   npm run dev
   ```

## 🐳 Docker Containerized Deployment

Run both backend and frontend with a single command:

```bash
docker compose up --build
```
- Frontend: `http://localhost:3000`
- Backend API: `http://localhost:8000`

## 📱 Mobile PWA Installation & Testing

Mobile browsers require a secure HTTPS context for camera access (`getUserMedia`). For local network testing:

1. **Option 1: Cloudflare Tunnel / Ngrok (Fastest)**
   ```bash
   cloudflared tunnel --url http://localhost:5173
   ```
   Open the HTTPS URL on your phone's browser.

2. **Option 2: Install as Standalone App**
   - **Android Chrome:** Tap the install banner or browser menu (⋮) → **"Install app"**.
   - **iOS Safari:** Tap the Share icon → **"Add to Home Screen"**.

## ⚠️ Known Limitations & Edge Cases

1. **iOS Motion Sensor Permissions:** iOS 13+ requires explicit user interaction to read `DeviceOrientationEvent`. Lumina provides a one-tap calibration button in Settings to grant permission.
2. **Camera Constraints Across Browsers:** Some mobile browsers (such as Firefox Mobile or iOS Safari) do not expose hardware torch or manual ISO/shutter controls. Lumina feature-detects all capabilities and degrades gracefully.
3. **Local Inference Hardware:** Running the 26B MoE variant locally in Ollama requires ~14–16 GB of VRAM. On lightweight laptops, configure `OLLAMA_MODEL=gemma4:e4b` or use Hosted Mode.
